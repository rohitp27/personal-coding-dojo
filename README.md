# personal-coding-dojo

By-hand C++ practice: warm-ups plus graded problems (101/102/201/301). See RUN.md for commands.

## Layout

- `practice/` your working exercises, including warm-ups and copies of 102 topics; `practice/cpp/PRIMER.md` is the refresher + cheat-sheet.
- `curriculum/` graded problems (101/102/201/301).
- `solutions/` reference answers mirroring `curriculum/` and `practice/cpp` primer (spoilers).

Practice and curriculum copies are independent. Run the exact file you edit; changes do
not sync between the two folders. See [RUN.md](RUN.md) for commands and a suggested workflow.
